# iGaming Player Retention & Snowflake KPI Reporting Pipeline

## Overview
An end-to-end **iGaming Data Analytics & KPI Reporting** solution engineered for **Snowflake Cloud Data Warehouse** and **JetBrains DataGrip**. Models 50,000+ sportsbook and casino betting transactions to automate executive KPI reporting (GGR, NGR, Hold %, ARPU), VIP player segmentation, and data support anomaly auditing.

## Tech Stack & Core Competencies
* **Cloud Data Warehouse:** Snowflake, SQL, JetBrains DataGrip
* **Domain Analytics:** iGaming (Sportsbook, Slots, Live Casino), GGR, NGR, ARPU, LTV Modeling
* **Data Engineering:** Python (`generate_igaming_data.py`) synthetic transaction pipeline
